# Catálogo de disciplinas — flow-guard

## Núcleo fixo (sempre, ao implementar)

- **test-driven-development** — "NO PRODUCTION CODE WITHOUT A FAILING TEST FIRST."
- **systematic-debugging** — reproduzir -> isolar -> diagnosticar -> corrigir com teste de regressão.
- **verification-before-completion** — rodar a suíte e confirmar saída antes de declarar pronto.

## Fechamento de feature (ao declarar pronto)

- **superpowers:requesting-code-review** — pede revisão estruturada antes de fechar.
- **commit-commands:commit-push-pr** — padroniza commit + push + PR.
- **superpowers:finishing-a-development-branch** — decide o destino da branch.
